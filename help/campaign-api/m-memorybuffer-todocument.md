# toDocument

从该缓冲区的文本内容返回XML文档。

```text
toDocument ( [codePage ])
```

## 参数

**codePage**&#x200B;对所用字符页进行编码的整数。 默认情况下，MemoryBuffer.CODEPAGE\_UTF8。

## 返回值

[DOMDocument](c-domdocument.md)类型对象。
