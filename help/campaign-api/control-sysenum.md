# SysEnum

此控件允许您从系统枚举中选择一个值。

![SysEnum控件](assets/sysenum.1eccf324.png)

## 属性

**backColor — 字符串**&#x200B;背景颜色（btnshadow，白色）。

**边框 — 字符串**&#x200B;更改控件轮廓样式（实线、双线、内缩、外凸、无）。

**defaultIfInvalid — 如果值无效，则使用字符串**&#x200B;值。

**枚举 — 要使用的字符串**&#x200B;枚举。

**font-size - integer**&#x200B;更改字体大小。

**标签 — 字符串**&#x200B;关联的标签。

**noInvalidErr — 布尔值**&#x200B;如果值无效，则不显示错误。

**nolabel — 布尔值**&#x200B;隐藏关联的标签。

**readOnly — 布尔值**&#x200B;强制控件为只读。

**必需 — 布尔值**&#x200B;字段为必填字段。

**序列化 — 布尔值**&#x200B;保存最后选择的值。

**useDesc - boolean**&#x200B;显示描述而不是标签。

**xpathEnum - xpath**&#x200B;使用此XPath引用的值而不是枚举属性。
