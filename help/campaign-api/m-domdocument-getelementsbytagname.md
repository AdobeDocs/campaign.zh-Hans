# getElementsByTagName

返回具有指定名称的所有元素的列表。

```text
getElementsByTagName (tagName)
```

## 参数

**tagName**&#x200B;搜索元素的名称。

## 返回值

包含元素列表的表。

## 备注

此方法为每个调用创建一个新表。 因此，最好将表保留在局部变量中，而不是进行多次调用。
