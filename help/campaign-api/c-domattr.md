# DOMAttr（类）

属性类型节点。

## 属性

| 属性 | 描述 |
| --- | --- |
| [isId](p-domattr-isid.md) | 如果属性是ID类型，则为true。 |
| [名称](p-domattr-name.md) | 属性名称。 |
| [ownerElement](p-domattr-ownerelement.md) | 具有此属性或null的元素。 |
| [已指定](p-domattr-specified.md) | 如果明确指定了该值，则为true（默认情况下，这不是隐式值）。 |
| [值](p-domattr-value.md) | 属性文本值。 |

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
