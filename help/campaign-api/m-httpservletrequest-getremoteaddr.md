# getRemoteAddr

返回客户端或上次发送请求的代理的IP地址。

```text
getRemoteAddr ()
```

## 参数

无。

## 返回值

包含发送查询的客户端的IP地址的字符串。

## 功能

**类的方法：** [HttpServletRequest](c-httpservletrequest.md)

**可用位置：**

* JSSP
* WebApp
