# 此项前插入

在特定位置之前插入节点。

```text
insertBefore (newChild, refChild)
```

## 参数

要插入的&#x200B;**newChild**&#x200B;节点。

**refChild**&#x200B;必须跟在节点后面才能插入的子节点。

## 返回值

插入的节点。

## 功能

**类的方法：** [DOMNode](c-domnode.md)

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
