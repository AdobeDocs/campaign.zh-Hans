# AddInstance

> 警告：此函数适用于内部部署环境。

在服务器上声明一个新实例

```text
AddInstance ( String instanceName, String hosts, String lang )
```

## 参数

要创建的实例的&#x200B;**instanceName**&#x200B;名称

**主机**&#x200B;与实例关联的DNS掩码

**lang**&#x200B;实例语言

## 返回值

无。

**架构：** [xtk:serverOptions](s-xtk-serveroptions.md)

**静态：**

是
