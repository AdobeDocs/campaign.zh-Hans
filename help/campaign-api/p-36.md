# 指令页面

包含函数库或字符串库。

## 语法

&lt;%@页面导入=&quot;lib1， ...&quot; %> &lt;%@页面stringGroup=&quot;groupName&quot; %>

## 描述

导入字符串库会公开一个全局JavaScript对象，其名称以sg\_开头，后跟特殊字符已替换为“\_”的库的名称。 例如，包含nms:campaign将创建sg\_nms\_campaign变量。

## 示例

```xml
      <%@ page import="xtk:shared/nl.js,nms:campaign.js" %>
<%@ page stringGroup="nms:campaign" %>
...
<%= sg_nms_campaign.stateLabel() %>
...
```
