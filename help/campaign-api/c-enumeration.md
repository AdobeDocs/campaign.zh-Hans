# 枚举（类）

表示枚举的定义。

## 属性

| 属性 | 描述 |
| --- | --- |
| [baseType](p-enumeration-basetype.md) | 返回提供枚举类型的字符串。 |
| [默认值](p-enumeration-default.md) | 返回提供枚举的默认值的字符串。 |
| [描述](p-enumeration-description.md) | 返回提供枚举说明的字符串。 |
| [hasImage](p-enumeration-hasimage.md) | 返回一个布尔值，它指示枚举是否具有图像。 |
| [标签](p-enumeration-label.md) | 返回提供枚举标签的字符串。 |
| [名称](p-enumeration-name.md) | 返回提供枚举名称的字符串。 |
| [值](p-enumeration-values.md) | 返回对象，其中每个属性都是一个按其值编制索引的[EnumerationValue](c-enumerationvalue.md)对象。 |

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
