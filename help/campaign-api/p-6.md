# 使用XML

许多JavaScript API将XML类型对象作为参数或返回它们。 Adobe Campaign的早期版本对此使用了JavaScript E4X扩展，该扩展允许直接在语言中处理XML元素。 然而，这项技术正在慢慢被放弃。

为了取代此技术，已添加新的对象来处理XML文档。 它们使用某些扩展恢复文档对象模型(DOM)界面的子集。 符号对象也可用于轻松创建XML文档，它是JXON BadgetFish约定的简化版本。

## DOM接口

[DOMDocument](c-domdocument.md)对象是XML文档。 它可以由字符串、JXON对象或直接从文件创建。 以下是创建DOM文档的示例：

```javascript
var doc  = new DOMDocument("recipient")
var root = doc.root
root.setAttribute("id", 12345)
var firstName = doc.createElement("firstName")
firstName.textContent = "John"
root.appendChild(firstName)

logInfo(doc.toXMLString(true))
```

此接口是W3C规范的一部分，但存在各种显着差异：

* 函数getElements\*以及childNodes和attributes属性返回JavaScript表而不是NodeList对象，这允许使用表自己的函数： forEach、map、...
* 当未指定值时，某些属性会返回空字符串而不是null。

此外，还增加了某些实用功能以及一些非标准扩展。 例如，要读取或修改属性，只需写入：

```javascript
aRecipient.$firstName
aRecipient.$firstName = "John"
```

而不是：

```javascript
aRecipient.getAttribute("firstName")
aRecipient.setAttribute("firstName", "John")
```

为具有$name属性的属性分配一个字符串、布尔值、日期或数字，该值将自动转换为字符串：

```javascript
aRecipient.$firstName = "John"
aRecipient.$lastModified = new Date()
aRecipient.$age = 35
aRecipient.$blocklist = false
```

## JXON

JXON是一种用于JavaScript对象的表示法约定，用于轻松构建XML文档。 此表示法不允许您创建所有可能的XML文档。 例如，它不允许您指定与属性同名的元素，并且命名空间不受管理。 它适用于Adobe Campaign文档。 对于更复杂的需求，您可以始终使用传统的DOM函数（按元素解析或创建元素）。 XML对象由JavaScript对象表示，该对象的属性与元素和属性相匹配。 值类型确定它是与元素还是属性有关。

* String值为字符串的属性
* 布尔值：值为“true”或“false”的属性
* 数字值为小数表示形式的属性
* Date其值表示日期和时间的ISO-8601表示的属性
* 对象An元素
* 数组A元素列表

名称为$的特殊属性用于元素的文本内容示例：

> **JXON：**
>
> ```javascript
> { alice: { $: "bob" } }
> ```
>
> **XML：**
>
> ```xml
> <alice>bob</alice>
> ```
>
> **JXON：**
>
> ```javascript
> { alice: { 
>     bob: { $: "charlie" }, 
>     david: { $: "edgar" }
> }}
> ```
>
> **XML：**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <david>edgar</david>
> </alice>
> ```
>
> **JXON：**
>
> ```javascript
> { alice: { 
>     bob: [
>         { $: "charlie" }, 
>         { $: "david" } ]
> }}
> ```
>
> **XML：**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <bob>david</bob>
> </alice>
> ```
>
> **JXON：**
>
> ```javascript
> { alice: { 
>     charlie: "david",
>     $: "bob"
> }}
> ```
>
> **XML：**
>
> ```xml
>                             <alice charlie="david">bob</alice>
> ```
>
> **JXON：**
>
> ```javascript
> { recipient: {
>     firstName: "John",
>     id: 1234,
>     "creation-date": getCurrentDate(),
>     blocklist: false
> }}
> ```
>
> **XML：**
>
> ```xml
> <recipient
>     firstName="John"
>     id="1234"
>     creation-date="2013-04-19 10:58:22Z"
>     blocklist="false"/>
> ```

当属性包含无效JavaScript标识符的特殊字符时，必须用引号引住这些字符。

```javascript
{ recipient: { "recipient-id" : 1234 }}
      
```

JXON对象可用于函数预期文档或XML元素的任何位置的参数中。 例如：

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
var query = NLWS.xtkQueryDef.create(doc)
```

等同于：

```javascript
var query = NLWS.xtkQueryDef.create({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
```

需要注意的是，处理XML文档是由DOM对象完成的，JXON对象是仅用于初始化的实用程序。 从文本的JavaScript结构创建XML文档会更加有用，尤其是当文档包含可变部件时。
