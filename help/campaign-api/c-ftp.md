# FTP（类）

通过FTP对象，您可以使用FTP协议执行许多操作。

## 方法

| 方法 | 描述 |
| --- | --- |
| [FTP](m-ftp-ftp.md) | 创建新对象以执行FTP命令。 |
| [处置](m-ftp-dispose.md) | 释放对象使用的资源。 |
| [列表](m-ftp-list.md) | 返回服务器上指定目录中的文件列表。 |
| [下载](m-ftp-download.md) | 将文件从服务器下载到本地文件或内存。 |
| [上传](m-ftp-upload.md) | 将文件从本地文件下载到FTP服务器。 |
| [setFile](m-ftp-setfile.md) | 定义传输模式和接收文件。 |

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法

* 工作流
