# 方案

返回所用协议的名称（HTTP、HTTPS等） 以访问此页面。

```text
scheme
```

## 备注

示例：以下URL的方案：

```javascript
      http://adobe.com:8080/nms/test.jst?id=1234&param=dummy#aFragment
```

返回以下字符串：

```javascript
http
```
