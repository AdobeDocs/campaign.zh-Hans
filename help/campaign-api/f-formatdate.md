# formatdate

将日期格式设置为字符串。

```text
formatDate (date, format [, timeZone ])
```

## 参数

**日期**&#x200B;转换的日期。

**format**&#x200B;描述要使用的格式的字符串。 用于设置日期不同部分的格式的字符如下：

* Y — 年
* M — 月份(1-12)
* B — 月份名称
* D — 日期(1-31)
* A — 日期名称
* J — 一年中的第几天(1-366)
* W — 一年中的第几周
* H — 小时(0-23)
* I — 小时(1-12)
* N — 分钟(0-59)
* S — 秒(0-59)
* P — 上午/下午

您可以在其中某些字符之前指定一个数字。 A和B字符后可跟l以使用全名，而不是缩写版本，也可跟i以使用英语名称。 示例：

* “%4Y/%2M/%2D”=> 2000/01/24。
* “%A %D %B %4Y”=> 2000年1月24日星期一。
* “%Al %D %Bl %4Y”=> 2000年1月24日星期一。
* “%02H：%02N：%02S”显示小时、分钟和秒的数字。

**时区**&#x200B;与时区对应的字符字符串。 xtk:common:时区枚举架构中指定了可能的值。

## 返回值

一个字符串，以请求的格式表示日期。
