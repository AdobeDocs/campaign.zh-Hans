# 使用日期

本章详细介绍了用于处理在服务器上执行的JavaScript程序（工作流、JSSP等）中日期的功能。

## 日期和时区

在JavaScript中，日期以UTC格式存储。 这意味着您只需担心构建日期或转换为文本字符串以进行内部显示或存储的时区对于日期转换，有两种函数类别：

* JavaScript库的函数(date.toString()、date.toLocaleString()、date.getHours()、...)，
* Adobe Campaign平台的功能( [formatDate(date， format)](f-formatdate.md) )。

按照惯例，首先使用计算机的时区，然后最后使用时区，具体取决于上下文：通常为当前操作员的时区，不过例如，可以为导出或工作流修改此行为。

## 获取当前日期

可通过两种方式在JavaScript中获取当前日期：

* new Date()创建一个新的Date对象，该对象以当前日期初始化。 日期与执行脚本的计算机的时间一致。
* [getCurrentDate()](f-getcurrentdate.md)基于数据库服务器的时间返回当前日期。

[getCurrentDate()](f-getcurrentdate.md)函数优于第一个解决方案，特别是在要与数据库中的其他日期进行比较或要写入数据库时。 此方法可减少由于应用程序服务器和数据库服务器之间的时间差异而导致出现差异（最长为几分钟）的风险

## 日期显示

为了显示目的，将日期转换为字符串将使用[formatDate](f-formatdate.md)函数。

## 从XML文档转换日期

在来自Adobe Campaign数据库的XML文档中存储的日期采用文本形式：可以使用[parseTimeStamp](f-parsetimestamp.md)函数转换这些日期。 这通常与[ExecuteQuery](sm-querydef-executequery.md)方法返回的XML文档有关。 示例：

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "get", 
    select: {
      node: {expr: "@lastModified"}
    }, 
    where: {
      condition: {expr: "@id=123456"}
    }
  }}
)

var delivery = query.ExecuteQuery()
var lastModified = parseTimeStamp(delivery.$lastModified)
```

## 在XML文档中插入日期

无论是在XML属性中写入日期、保存文档（[Write](sm-session-write.md)方法）还是在查询表达式中插入文本日期，都必须将日期转换为ISO8601格式。 xtk:shared/nl.js函数库中有用于将日期转换为此格式的方法：NL.XTK.formatDateTime(date)方法。 可以使用loadLibrary函数加载库：

```javascript
loadLibrary("xtk:shared/nl.js")
```

或者，在动态JavaScript page (JSSP)的情况下使用page指令：

```xml
<%@ page import="xtk:shared/nl.js" %>
```

警告：不能对所有脚本使用loadLibrary。 例如，您不能在电子邮件个性化脚本中更改JavaScript功能库。 示例：此示例显示使用文本日期构建查询。

```javascript
loadLibrary("xtk:shared/nl.js")
NL.require('/nl/core/shared/xtk.js')
...

var date = ...

var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "select", 
    select: {
      node: {expr: "@id"}
    }, 
    where: {
      condition: {expr: "@lastModified > #" + NL.XTK.formatDateTime(date) + "#"}
    }
  }})

var result = query.ExecuteQuery()
```
