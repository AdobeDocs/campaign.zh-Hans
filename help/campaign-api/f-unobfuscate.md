# 取消模糊处理

由于[模糊处理](f-obfuscate.md)，因此取消模糊处理以前模糊处理的整数。

```text
unobfuscate (value [, version ])
```

## 参数

**value**&#x200B;要模糊处理的整数。

**版本**&#x200B;要应用的取消模糊处理版本。 默认情况下，为0。

## 返回值

以前被[模糊处理](f-obfuscate.md)模糊处理的整数。

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
