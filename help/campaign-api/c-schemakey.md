# SchemaKey（类）

表示键的定义。

## 属性

| 属性 | 描述 |
| --- | --- |
| [标签](p-schemakey-label.md) | 返回键的简短描述。 |
| [描述](p-schemakey-description.md) | 返回键的描述。 |
| [名称](p-schemakey-name.md) | 返回键的标识符。 |
| [isInternal](p-schemakey-isinternal.md) | 如果它们键是内部键，则返回true。 |
| [allowEmptyPart](p-schemakey-allowemptypart.md) | 如果键的字段可以为空（必须至少输入其中一个字段），则返回true。 |
| [字段](p-schemakey-fields.md) | 返回包含键的字段([SchemaNode](c-schemanode.md))的表。 |

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
