# SaveUrlInfo

将此投放的 URL 另存为 URL 模板。

```text
SaveUrlInfo ( XML insUrlList, XML updUrlList )
```

## 参数

**insUrlList**&#x200B;新URL列表（不与URL模板关联）

**updUrlList**&#x200B;要更新的URL模板列表

## 返回值

无。

## 功能

**架构：** [nms:delivery](s-nms-delivery.md)

**静态：**

是
