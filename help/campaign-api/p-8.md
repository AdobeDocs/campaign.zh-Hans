# 数据保护：转义功能

Adobe Campaign提供了一系列功能，用于防御最常见的攻击：SQL注入、XSS攻击等。

逃逸功能应在运营商的监督下使用，Adobe对开发过程中这些功能的不当使用或不使用不承担任何责任。

一般规则如下：

**所有参数都必须转义。 用于转义的函数取决于数据的目标格式。**

## 简化的转义

在JSSP中，Adobe Campaign提供了“&lt;%=”标记，通过此标记，您可以转义在生成的XML或HTML实体中使用的变量。 此方法更方便，等效于NL.XML.escape()。 以下示例说明了如何使用标记对参数进行转义：

```xml
<li>
<%= strRecipientList %>
</li>
```

## 高级转义：

Adobe Campaign提供了4个函数，这些函数允许您根据目标格式对参数进行转义。要访问这些转义函数，请分别命名以下文件：

```javascript
NL.require('/nl/core/shared/xml.js')
NL.require('/nl/core/sql.js')
NL.require('/nl/core/shared/xtk.js')
NL.require('/nl/core/shared/js.js')
```

* NL.XML.escape(data)用于对生成的XML或HTML实体中使用的变量进行转义。 此函数等同于“&lt;%=”语法。 此函数在NL.XML包中定义。

  ```xml
  <tr>
  <td><%==NL.XML.escape(node.id)%><td>
  <td><%==NL.XML.escape(node.label)%><td>
  </tr>
  ```

* NL.SQL.escape(data)用于转义可在SQL查询中使用的参数。 此函数自动将表达式放置在简单引号之间。 此函数在NL.SQL包中定义。

  ```javascript
            var strSql = "UPDATE NmsRecipient SET sEmail="+NL.SQL.escape(strEmail)+ " WHERE ...";
  ```

* NL.XTK.toXTKString(data) ，用于转义预定在XTK表达式中使用的参数。 此函数在NL.XTK包中定义。

  ```javascript
  var query = NLWS.xtkQueryDef.create(
    {queryDef: {schema: "nms:recipient", operation: "select", 
      select: {
        node: [
          {expr: "@firstName"}, 
          {expr: "@lastName"} 
        ]
      }, 
      where: {
        condition: {expr: "@email=" + NL.XTK.toXTKString(request.getParameter("query"))}
      }
    }})
  ```

* NL.JS.escape(data)，用于对客户端执行的javascript中使用的变量进行转义。 此函数在NL.JS包中定义。

  ```xml
  <script type="text/javascript">
                var value = “Foo <%== NL.JS.escape(Node.@value) %>”; 
  </script>
  ```

警告： Adobe Campaign不保证这些函数在更高版本中的持久性。
