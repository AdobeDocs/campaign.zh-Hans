# createtrackinginstanceshell

在重定向服务器上创建或配置跟踪实例

```text
CreateTrackingInstanceShell ( String internalPwd, String serverUrlList, String instanceName, String cryptedPassword, String host )
```

## 参数

**internalPwd**&#x200B;内部密码

**serverUrlList**&#x200B;跟踪服务器的内部URL

要创建的实例的&#x200B;**instanceName**&#x200B;名称

**cryptedPassword**&#x200B;加密密码

与实例关联的&#x200B;**主机** DNS掩码

## 返回值

无。

## 功能

**架构：** [nms:trackingUrl](s-nms-trackingurl.md)

**静态：**

是
