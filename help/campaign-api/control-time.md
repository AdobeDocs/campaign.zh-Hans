# 时间

时间类型控件允许您输入一天中的时间。

![时间控件](assets/time.0ff42b85.png)

## 属性

**backColor — 字符串**&#x200B;背景颜色（btnshasow，白色）。

**边框 — 字符串**&#x200B;更改控件的边框样式（实线、双线、内缩、外凸、无）。

**font-size - integer**&#x200B;更改字体大小。

**标签 — 字符串**&#x200B;关联的标签。

**nolabel — 布尔值**&#x200B;隐藏关联的标签。

**readOnly — 布尔值**&#x200B;强制控件为只读。

**必需 — 布尔值**&#x200B;字段为必填字段。
