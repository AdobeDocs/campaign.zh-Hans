# transitionByType

返回与给定类型对应的过渡。

```text
transitionByType (type)
```

## 参数

**类型**&#x200B;过渡类型。

## 返回值

将类型作为参数传递的第一个过渡，如果活动没有此类型的过渡，则为空。
