# setFile

> 警告：
>
> 通过文件API进行的访问仅限于&#x200B;**var**、**sftp**&#x200B;和Adobe Campaign的临时文件夹。

定义传输模式和接收文件。

```text
setFile (filename)
```

## 参数

**文件名**&#x200B;本地文件的名称。

## 返回值

无。

## 功能

**类的方法：** [FTP](c-ftp.md)

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
