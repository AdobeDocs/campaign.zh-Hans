# getUUID

生成唯一标识符（通用唯一标识符）。

```text
getUUID ()
```

## 参数

无。

## 返回值

一个字符串，其中包含唯一的“550E8400-E29B-41D4-A716-446655440000”类型ID。

* 内容管理
* 投放属性
* 类型规则
* JSSP

* WebApp
* 工作流
