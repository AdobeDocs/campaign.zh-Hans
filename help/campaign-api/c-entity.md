# 实体（类）

表示给定模式的数据库实体。

此类对象无法直接实例化。 必须使用create()、get()或load()方法。

## 方法

| 方法 | 描述 |
| --- | --- |
| [保存](m-entity-save.md) | 在数据库中保存实体。 |

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
