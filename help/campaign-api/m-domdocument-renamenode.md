# renameNode

更改元素或属性的名称。

```text
renameNode (node, namespaceURI, qualifiedName)
```

## 参数

**节点**&#x200B;元素/属性类型节点。

**namespaceURI**&#x200B;新命名空间URI。

**限定名**&#x200B;新限定名。

## 返回值

已重命名节点。 这可以是指定的节点或替换旧节点的节点。

## 功能

**类的方法：** [DOMDocument](c-domdocument.md)

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
