# hasAttributeNS

测试属性的存在。

```text
hasAttributeNS (namespaceURI, localName)
```

## 参数

属性命名空间的&#x200B;**namespaceURI** URI。

**localName**&#x200B;属性名称。

## 返回值

如果属性存在，则为true ；否则为false。
