# getOption

返回选项表中选项的值。

```text
getOption (name [, useCache ])
```

## 参数

**名称**&#x200B;选项的名称。

**useCache**&#x200B;使用选项值缓存（默认情况下，不使用）。

## 返回值

如果选项存在，则为选项的值，否则为未定义。 值的类型取决于选项的类型。

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
