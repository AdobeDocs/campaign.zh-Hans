# setEnv

>[!WARNING]
>
>此函数适用于内部部署环境。

>[!NOTE]
>
>您可以将&#x200B;**XtkSecurity\_Disable\_GetSetEnv**&#x200B;选项传递给&#x200B;**true**&#x200B;来禁用此函数。

设置环境变量的值。

```text
setEnv (name, value)
```

## 参数

**name**&#x200B;环境变量的名称。

**值**&#x200B;环境变量的新值。

## 返回值

变量的新值。

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
