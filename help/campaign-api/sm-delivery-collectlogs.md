# CollectLogs

为投放列表创建一个包含所有投放日志消息的表

```text
CollectLogs ( Number id, XML deliveries, String logTable )
```

## 参数

**id**&#x200B;优先级唯一标识符

**个投放**&#x200B;要考虑的投放列表

要创建的&#x200B;**logTable**&#x200B;表包含所有日志消息

## 返回值

无。

## 功能

**架构：** [nms:delivery](s-nms-delivery.md)

**静态：**

是
