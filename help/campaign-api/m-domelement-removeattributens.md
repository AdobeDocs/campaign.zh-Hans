# removeAttributeNS

删除属性。

```text
removeAttributeNS (namespaceURI, localName)
```

## 参数

属性命名空间的&#x200B;**namespaceURI** URI。

**localName**&#x200B;属性名称。

## 返回值

无。

## 备注

如果元素没有此名称的属性，则此方法不起作用。
