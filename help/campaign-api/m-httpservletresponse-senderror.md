# sendError

使用作为参数传递的错误代码返回错误响应。

```text
sendError (errorCode)
```

## 参数

**错误代码** HTTP错误代码。

## 返回值

无。

## 功能

**类的方法：** [HttpServletResponse](c-httpservletresponse.md)

**可用位置：**

* JSSP
* WebApp
