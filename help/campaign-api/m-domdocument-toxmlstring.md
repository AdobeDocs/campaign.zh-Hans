# toXMLString

将XML文档转换为字符串。

```text
toXMLString (format)
```

## 参数

**格式**&#x200B;用于设置XML文档格式的布尔值。

## 返回值

无。

## 备注

此方法会添加prolog，不同于对元素使用相同名称的方法。

**类的方法：** [DOMDocument](c-domdocument.md)

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
