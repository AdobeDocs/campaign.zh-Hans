# 数字

此控件允许您输入数字。

![数字控件](assets/number.d018cb51.png)

## 属性

**backColor — 字符串**&#x200B;背景颜色（btnshadow，白色）。

**边框 — 字符串**&#x200B;在控件期间更改边框样式（实线、双线、内缩、外凸、无）。

**digitCount - integer**&#x200B;逗号后面要显示的数字数。 默认值为2。

**font-size - integer**&#x200B;更改字体大小。

**标签 — 字符串**&#x200B;关联的标签。

**nolabel — 布尔值**&#x200B;隐藏关联的标签。

**readOnly — 布尔值**&#x200B;强制控件为只读。

**必需 — 布尔值**&#x200B;字段为必填字段。

**宽度 — integer**&#x200B;要显示的字符数。 默认值为18，与000 000 000 000.00一致。
