# localOrder

分布式营销的程序包中的本地 Campaign 订单

## 方法

| 方法 | 描述 |
| --- | --- |
| [取消](sm-localorder-cancel.md) | 取消订单。 |
| [CreateFromCatalog](sm-localorder-createfromcatalog.md) | 从程序包创建订单。 |
| [EvaluateContent](sm-localorder-evaluatecontent.md) | 评估链接到订单的投放内容。 此评估将在使用操作员权限订购时以及在创建本地营销活动之前执行。 |
| [EvaluateContentFromId](sm-localorder-evaluatecontentfromid.md) | 评估链接到订单的投放内容。 此评估将在使用操作员权限订购时以及在创建本地营销活动之前执行。 |
| [EvaluateDeliveryBudget](sm-localorder-evaluatedeliverybudget.md) | 评估投放预算。 |
| [EvaluateTarget](sm-localorder-evaluatetarget.md) | 评估与订单关联的每个活动投放的活动定位。 此评估将在使用操作员权限订购时以及在创建本地营销活动之前执行。 |
| [EvaluateTargetFromId](sm-localorder-evaluatetargetfromid.md) | 评估与订单关联的每个活动投放的活动定位。 此评估将在使用操作员权限订购时以及在创建本地营销活动之前执行。 |
| [ExecuteTarget](sm-localorder-executetarget.md) | 执行与订单关联的营销活动目标选择。 |
| [保留](sm-localorder-reserve.md) | 顺序。 |
| [验证](sm-localorder-validation.md) | 审批订单。 |
