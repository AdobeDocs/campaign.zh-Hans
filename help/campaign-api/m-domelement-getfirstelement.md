# getFirstElement

通过验证给定的标准返回第一个子元素。

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## 参数

**tagName**&#x200B;搜索元素的名称。

**attrName**&#x200B;必须验证给定值的属性的名称。

**attrValue**&#x200B;属性值。

## 返回值

第一个元素用于验证给定的标准或null。
