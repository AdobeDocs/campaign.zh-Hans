# JavaScript例外

默认情况下，当发生错误时，正在执行的脚本将被中断。 但是，版本4.05以后的确允许您捕获错误并处理它们，以便继续处理脚本。

Adobe Campaign引发的异常是错误代码（`Number`类型）。

## 示例

此示例尝试从无效地址恢复网页，并从[getUrl()](f-geturl.md)函数引发异常。

```javascript
try
{
  var url = "xx:/invalid-url"
  getUrl(url)
}
catch(e)
{
  logInfo("Can't get page content: " + url )
  logInfo("Error number: " + e )
}

  
```
