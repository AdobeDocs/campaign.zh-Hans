# GetAccessInfo

返回匿名模式的继承属性。

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## 参数

**categoryId**&#x200B;类别ID

## 返回值

**匿名**&#x200B;指定类别优惠是否匿名

**parentAnonymous**&#x200B;指定父类别优惠是否匿名

**架构：** [nms:offerCategory](s-nms-offercategory.md)
