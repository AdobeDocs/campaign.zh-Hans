# RestartTask

强制重新启动一个或多个已完成的任务。

```text
RestartTask ( String workflowId, String activityName )
```

## 参数

**workflowId**&#x200B;工作流的标识符或内部名称。

要重新启动的&#x200B;**activityName**&#x200B;活动名称

## 返回值

无。

## 功能

**架构：** [xtk:workflow](s-xtk-workflow.md)

**静态：**

是
