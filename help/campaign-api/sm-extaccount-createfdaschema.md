# CreateFDASchema

在数据库中创建工作架构

```text
CreateFDASchema ( String server, String account, String password, String port, String options, String schema )
```

## 参数

**服务器**&#x200B;服务器地址

**帐户**&#x200B;帐户的名称（或登录名）

**密码**&#x200B;与帐户关联的密码

**端口**&#x200B;服务器端口

**选项**&#x200B;连接选项

**架构**&#x200B;架构名称

## 返回值

无。

## 功能

**架构：** [nms:extAccount](s-nms-extaccount.md)

**静态：**

是
