# 保存

> 警告：
>
> 通过文件API进行的访问仅限于&#x200B;**var**、**sftp**&#x200B;和Adobe Campaign的临时文件夹。

将缓冲区的内容保存到文件中。

```text
save (filename)
```

## 参数

**filename**&#x200B;要保存的文件名。

## 返回值

无。

## 功能

**类的方法：** [MemoryBuffer](c-memorybuffer.md)

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
