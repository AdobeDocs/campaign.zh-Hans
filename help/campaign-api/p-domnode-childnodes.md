# childNodes

以表的形式返回子节点的列表。

```text
childNodes
```

## 备注

此属性为每次访问创建一个新表。 因此，最好将表保留在局部变量中，而不是多次访问属性。

## 功能

**类的属性：** [DOMNode](c-domnode.md)

**只读：**

是

* 投放属性
* 投放消息
