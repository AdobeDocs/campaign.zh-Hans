# toString

以字符串形式返回[MemoryBuffer](c-memorybuffer.md)的内容。

```text
toString ( [codePage ])
```

## 参数

**codePage**&#x200B;对所用字符页进行编码的整数。 默认情况下，MemoryBuffer.CODEPAGE\_UTF8。

## 返回值

字符串形式的图章内容。
