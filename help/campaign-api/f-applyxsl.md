# applyxsl

使用XSL样式表转换XML文档。

```text
applyXsl (xslEntity, xml)
```

## 参数

**xslEntity**&#x200B;存储在数据库中的XSL样式表的名称。

**xml**&#x200B;包含要转换的XML文档的XML文档或字符串。

## 返回值

转换后字符串形式的XML文档。

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
