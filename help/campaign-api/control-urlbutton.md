# Url按钮

行为类似于按钮的超链接。

![UrlButton控件](assets/urlbutton.d1cf6f42.png)

## 属性

**backColor — 字符串**&#x200B;背景颜色（btnshadow，白色）。

**边框 — 字符串**&#x200B;更改控件轮廓样式（实线、双线、内缩、外凸、无）。

**font-size - integer**&#x200B;更改字体大小。

**img — 字符串**&#x200B;关联的图像。

**标签 — 按钮的字符串**&#x200B;标签。
