# 完整性

返回链接完整性类型。

```text
integrity
```

## 备注

属性可以采用以下值之一：

* Schema.INTEGRITY\_NORMAL - “正常”类型链接。
* Schema.INTEGRITY\_DEFINE - “定义”类型链接。
* Schema.INTEGRITY\_NEUTRAL - “中性”类型链接。
* Schema.INTEGRITY\_USED - “已使用”类型链接。
* Schema.INTEGRITY\_OWN - &quot;own&quot;类型链接。
* Schema.INTEGRITY\_OWNCOPY - &quot;owncopy&quot;类型链接。
