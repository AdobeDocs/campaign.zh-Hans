# HttpServletResponse（类）

表示返回给客户端的servlet的响应。

此类只有一个实例可由`response`变量访问。

## 方法

| 方法 | 描述 |
| --- | --- |
| [setContentType](m-httpservletresponse-setcontenttype.md) | 更改响应的文档类型。 |
| [sendRedirect](m-httpservletresponse-sendredirect.md) | 返回到其他URL的临时重定向。 |
| [addCookie](m-httpservletresponse-addcookie.md) | 向响应添加Cookie。 |
| [addHeader](m-httpservletresponse-addheader.md) | 向响应添加一个额外的HTTP标头。 |
| [发送错误](m-httpservletresponse-senderror.md) | 使用作为参数传递的错误代码返回错误响应。 |

## 功能

**可用位置：**

* JSSP
* WebApp
