# 冲突

> 警告：此函数适用于内部部署环境。

冲突实体的临时存储。

## 方法

| 方法 | 描述 |
| --- | --- |
| [AcceptCus](sm-conflict-acceptcus.md) | 保留当前版本。 |
| [AcceptNew](sm-conflict-acceptnew.md) | 接受新版本作为当前版本。 |
| [SetResolved](sm-conflict-setresolved.md) | 声明一个实体不再有冲突。 |

## 常规方法

| 方法 | 描述 |
| --- | --- |
| [创建](f-create.md) | 创建与给定架构对应的新实体。 |
| [加载](f-load.md) | 加载并返回与给定架构和键对应的实体。 |
| [保存](m-entity-save.md) | 在数据库中保存实体。 |
