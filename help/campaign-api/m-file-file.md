# 文件

创建与文件关联的新对象。

```text
File (filename)
```

## 参数

**文件名**&#x200B;要读取或创建的文件的名称。

## 返回值

无。

## 备注

示例：

```javascript
var f = new File("/tmp/file.txt")
```
