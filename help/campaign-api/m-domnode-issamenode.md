# isSameNode

测试给定的引用是否表示同一节点。

```text
isSameNode ()
```

## 参数

无。

## 返回值

如果两个引用表示同一节点，则为true ；否则为false。

## 备注

必须使用此方法来比较两个引用，不能使用JavaScript运算符==和===。
