# hmacStr

计算字符串的MD5、SHA-1或SHA-256哈希值。 该字符串在计算之前会自动使用UTF-8进行编码。

```text
hmacStr (string [, key ] [, algo ])
```

## 参数

**字符串**&#x200B;要计算哈希的字符串。

**key**&#x200B;键，字符串形式。 它会自动转换为UTF-8。 如果缺少密钥，则服务器将使用依赖于实例的密钥，并且该密钥仅在此实例上有效。

**算法**&#x200B;要使用的哈希类型。 可能的值为“MD5”、“SHA1”或“SHA256”。 忽略大小写，因此可以使用小写或大写输入值。 如果未指定参数，则默认情况下会选中值“SHA1”。

## 返回值

作为参数传递的字符串的MD5、SHA-1或SHA-256哈希（取决于选择的哈希类型）。

## 备注

对于MD5和SHA-1类型，转换为UTF-8后，密钥最长可为64个字符（512位）。 对于SHA-256类型，密钥在转换为UTF-8后最多可包含32个字符（256位）。
