# WebPostUpload

根据使用的存储类型，在上传（从网页）到服务器后最终确定资源的存储。 恢复代码页和内容类型。

```text
fileRes.WebPostUpload ( XML params )
```

## 参数

**参数**&#x200B;对于“工作区”类型存储：@formerFileName包含工作区中的先前名称。 如果要立即保存实体：@immediateSave必须设置为“true”

## 返回值

无。
