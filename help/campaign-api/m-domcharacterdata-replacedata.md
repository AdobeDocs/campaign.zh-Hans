# replaceData

替换部分文本。

```text
replaceData (offset, count, arg)
```

## 参数

**offset**&#x200B;要删除的第一个字符的位置（第一个字符为0）。

**count**&#x200B;要删除的字符数。

要插入的&#x200B;**arg**&#x200B;字符串。

## 返回值

无。
