# digestStrSha1

> 警告：
>
> 不得使用此函数根据个人信息创建哈希。

计算字符串的SHA-1哈希值。 该字符串在计算之前会自动使用UTF-8进行编码。

```text
digestStrSha1 (string)
```

## 参数

**字符串**&#x200B;要计算哈希的字符串。

## 返回值

作为参数传递的字符串的SHA-1哈希。
