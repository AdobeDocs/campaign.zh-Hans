# digestStrSha256

计算字符串的SHA-256哈希。 该字符串在计算之前会自动使用UTF-8进行编码。

```text
digestStrSha256 (string)
```

## 参数

**字符串**&#x200B;要计算哈希的字符串。

## 返回值

作为参数传递的字符串的SHA-256哈希。

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
