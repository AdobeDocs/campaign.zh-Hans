# 文件编辑

此控件允许您输入文件名。

![FileEdit控件](assets/fileedit.56228d2a.png)

## 属性

**backColor — 字符串**&#x200B;背景颜色（btnshasow，白色）。

**边框 — 字符串**&#x200B;在控件期间更改边框样式（实线、双线、内缩、外凸、无）。

**dlgType - string**&#x200B;文件选择窗口的类型（保存、opendir、savedir）。

**筛选器 — 字符串**&#x200B;筛选器列表

**font-size - integer**&#x200B;更改字体大小。

**标签 — 字符串**&#x200B;关联的标签。

**lastPath — 字符串**&#x200B;文件选择窗口的路径。

**loadContent — 布尔值**&#x200B;加载文件的内容。

**nolabel — 布尔值**&#x200B;隐藏关联的标签。

**readOnly — 布尔值**&#x200B;强制控件为只读。

**必需 — 布尔值**&#x200B;字段为必填字段。

**标题 — 字符串**&#x200B;选择窗口的标题

**xpathCopyName - xpath**&#x200B;用于存储文件名的路径（扩展名为）。

**xpathType - xpath**&#x200B;文件类型（文本或XML）
