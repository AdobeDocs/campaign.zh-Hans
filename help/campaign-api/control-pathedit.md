# 路径编辑

用于选择字段的控件。

## 属性

**backColor — 字符串**&#x200B;背景颜色（btnshadow，白色）。

**边框 — 字符串**&#x200B;更改控件轮廓样式（实线、双线、内缩、外凸、无）。

**font-size - integer**&#x200B;更改字体大小。

**hideCalculated - boolean**&#x200B;隐藏计算字段。

**hideMappedAsXml - boolean**&#x200B;隐藏XML字段。

**标签 — 字符串**&#x200B;关联的标签。

**nolabel — 布尔值**&#x200B;隐藏关联的标签。

**noTransaction — 布尔值**&#x200B;禁用事务模式。

**readOnly — 布尔值**&#x200B;强制控件为只读。

**必需 — 布尔值**&#x200B;字段为必填字段。

**useLink11Path — 布尔值**&#x200B;显示1:1链接。

**useTablePath — 布尔值**&#x200B;显示表。

**useUnboundPath - boolean**&#x200B;显示集合。

**xpath - string**&#x200B;要编辑的字段。

**xpathBaseType - xpath**&#x200B;用于存储所选字段类型的路径。

**xpathDataPolicy - xpath**&#x200B;用于存储所选字段的dataPolicy属性的路径。

**xpathEnum - xpath**&#x200B;用于存储所选字段的系统枚举的路径。

**xpathLabel — 字符串**&#x200B;用于存储所选字段的标签的路径。

**xpathSchema - string**&#x200B;架构路径。

**xpathSchemaMd5 - xpath**&#x200B;用于存储架构的MD5的路径。

**xpathStartPath - startPath的字符串**&#x200B;路径（仅在定义xpathSchema时使用）。

**xpathUnbound - xpath**&#x200B;用于存储所选字段的未绑定属性的路径。

**xpathUserEnum - xpath**&#x200B;用于存储所选字段的可用枚举的路径。

**xpathType - xpath**&#x200B;用于存储所选字段的默认控件的路径。

**缩放 — 布尔值**&#x200B;显示编辑按钮。
