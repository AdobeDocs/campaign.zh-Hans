# 重新计算统计信息

重新计算投放操作的投放和跟踪统计信息。

```text
RecomputeStats ( Number deliveryId, Number dirtyFlags )
```

## 参数

**deliveryId**&#x200B;投放标识符

描述要重新计算的内容的&#x200B;**dirtyFlags**&#x200B;位字段（请参阅“nms:delivery:dirtyFlags”枚举）。

## 返回值

无。

**架构：** [nms:delivery](s-nms-delivery.md)

是
