# 加载

将文件的内容加载到缓冲区。

```text
load (filename)
```

## 参数

**filename**&#x200B;要加载的文件的名称。

## 返回值

无。

* 内容管理
* 投放属性

* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
