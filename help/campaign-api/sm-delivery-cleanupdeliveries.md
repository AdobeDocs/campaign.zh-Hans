# CleanupDeliveries

指定中间源服务器应删除某些投放。

```text
CleanupDeliveries ( String deliveryId )
```

## 参数

**deliveryId**&#x200B;发送数据库中的投放标识符列表（逗号分隔）

## 返回值

无。
