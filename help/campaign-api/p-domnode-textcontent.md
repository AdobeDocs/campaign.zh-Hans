# textContent

节点的文本内容。 该值取决于节点的类型。

```text
textContent
```

## 备注

此属性可使用读取和写入权限进行访问。

## 功能

**类的属性：** [DOMNode](c-domnode.md)

**只读：**

是

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
