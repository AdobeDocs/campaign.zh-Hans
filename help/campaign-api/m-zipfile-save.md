# 保存

保存存档。

```text
save ( [filename ] [, overwrite ])
```

## 参数

**文件名**&#x200B;存档的名称。 如果未指定该名称或该名称为空，则存档将以其原始名称保存。

**覆盖**&#x200B;如果为“false”，则存档将不被保存，如果已存在具有此名称的文件，将引发异常。

## 返回值

无。
