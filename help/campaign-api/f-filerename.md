# fileRename

更改文件的名称。

如果未指定字符编码，则使用服务器默认值。

```text
fileRename (oldname, newname)
```

## 参数

**oldname**&#x200B;要重命名的文件的全名。

**newname**&#x200B;文件的新名称。

## 返回值

无。

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
