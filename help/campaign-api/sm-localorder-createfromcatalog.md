# CreateFromCatalog

从程序包创建订单。

```text
XML localOrder = CreateFromCatalog ( Number catalogId, Number orgUnitId )
```

## 参数

**catalogId**&#x200B;包ID。

**orgUnitId**&#x200B;本地实体标识。 （可选）

## 返回值

**localOrder**&#x200B;返回创建的订单。

**架构：** [nms:localOrder](s-nms-localorder.md)
