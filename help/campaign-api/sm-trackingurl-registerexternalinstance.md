# RegisterExternalInstance

为重定向服务器审批中继服务器上的跟踪实例（通过设置数据库标识符）。

```text
RegisterExternalInstance ( String login, String instanceName, String dbId, Boolean saveParams )
```

## 参数

**登录**&#x200B;中继服务器访问登录

要批准的实例的&#x200B;**instanceName**&#x200B;名称

执行投放的客户的&#x200B;**dbId**&#x200B;数据库标识符

**saveParams**&#x200B;保存选项（如果成功）

## 返回值

无。

## 功能

**架构：** [nms:trackingUrl](s-nms-trackingurl.md)

**静态：**

是
