# 示例

## 静态方法

访问SOAP方法通过在表示模式的对象上调用方法来实现。 架构是“NLWS”全局对象。 以下示例调用[xtk:workflow](s-xtk-workflow.md)架构的[PostEvent](sm-workflow-postevent.md)静态方法。

```javascript
      NLWS.xtkWorkflow.PostEvent("WKF1", "signal", "", {variables: {foo: 'bar'}}, false)
    
```

## 非静态方法

若要使用非静态SOAP方法，必须先使用相应架构上的[load](f-load.md)或[create](f-create.md)方法恢复实体。 以下示例调用[xtk:queryDef](s-xtk-querydef.md)架构的[ExecuteQuery](sm-querydef-executequery.md)方法。

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "xtk:workflow", operation: "select", 
    select: {
      node: {expr: "@internalName"}
    }, 
    where: {
      condition: {expr: "[folder/@name]='wfExamples'"}
    }, 
    orderBy: {
      node: {expr: "@internalName", sortDesc: "false"}
    }
  }})

var res = query.ExecuteQuery()

for each (var w in res.getElements("workflow"))
  logInfo(w.$internalName)
    
```

## 限制

无法使用某些非静态调用，因为要加载的对象(\*\*)缺少数据。 例如，[nms:delivery](s-nms-delivery.md)上的某些调用就是这种情况。
