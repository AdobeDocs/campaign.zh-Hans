# fromHexString

在缓冲区中加载十六进制字符串的内容。

```text
fromHexString (string)
```

## 参数

**字符串**&#x200B;表示要添加到缓冲区的以十六进制编码的二进制数据的字符字符串。

## 返回值

无。
