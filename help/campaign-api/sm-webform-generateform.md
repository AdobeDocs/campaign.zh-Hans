# 生成表单

以邮件或 Web 模式生成表单

```text
String result = GenerateForm ( String formName, Boolean mailMode )
```

## 参数

**formName**&#x200B;表单名称

**mailMode**&#x200B;生成邮件类型的表单

## 返回值

**结果**&#x200B;在表单上应用XSL的结果

**架构：** [nms:webForm](s-nms-webform.md)
