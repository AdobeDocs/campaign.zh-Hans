# addHeader

向响应添加一个额外的HTTP标头。

```text
addHeader (nom, valeur)
```

## 参数

要添加的标头的&#x200B;**nom**&#x200B;名称。

已添加标头的&#x200B;**valeur**&#x200B;值。

## 返回值

无。

## 功能

**类的方法：** [HttpServletResponse](c-httpservletresponse.md)

**可用位置：**

* JSSP
* WebApp
