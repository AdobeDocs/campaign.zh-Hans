# logInfo

向工作流实例的日志添加一条信息消息。

```text
logInfo (message)
```

## 参数

**消息**&#x200B;要添加到日志中的消息。

## 返回值

无。

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
