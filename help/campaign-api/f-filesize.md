# fileSize

返回文件的大小（字节）。

```text
fileSize (filename)
```

## 参数

**filename**&#x200B;文件的全名。

## 返回值

返回文件的大小，如果发生错误（例如，如果找不到文件），则返回–1。

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
