# E4X迁移指南

Mozilla逐步放弃了在JavaScript中原生支持XML的E4X扩展。 Adobe Campaign大量使用此扩展，因此它正准备迁移到替代解决方案。

本指南旨在通过描述替换解决方案来帮助您迁移现有配置或开发新配置。

新旧系统并存，当前版本的Adobe Campaign始终与E4X兼容，但新配置不得与E4X扩展一起开发。

提醒： E4X添加了一种JavaScript xml类型，可以直接从源程序构建：

```text
var doc = <xml> ... </xml>
```

或从字符串：

```text
var doc = new XML ("<xml>...</xml>")
```

然后，可以使用特定API对其进行操作：

```text
element.@id element.where
```

## XML类型

本机“xml”类型已由DOM API替换，这些是[DOMDocument](c-domdocument.md)、[DOMElement](c-domelement.md)、[DOMNode](c-domnode.md)类型……以下是最常见的等效操作：

> **E4X：**
>
> ```javascript
> anElement.@id
> ```
>
> **DOM：**
>
> ```javascript
> anElement.$id
> ```
>
> **E4X：**
>
> ```javascript
> anElement.@["recipient-id"]
> ```
>
> **DOM：**
>
> ```javascript
> anElement["$recipient-id"]
> ```
>
> **E4X：**
>
> ```javascript
> anElement.childElement
> ```
>
> **DOM：**
>
> ```javascript
> anElement.getElements("childElement")
> ```
>
> 或者
>
> ```javascript
> anElement.getFirstElement("childElement")
> ```

必须替换JavaScript中的XML文档。 当此文档将用于本机函数或用于在参数中传递XML文档的SOAP调用时，您可以直接传递JXON。 这将自动转换为XML文档(DOMDocument)。 如果不能，您可以始终通过JXON对象进行传递，但需要使用[DOMDocument.fromJXON](m-domdocument-fromjxon.md)函数进行显式转换。

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
{schema: "xtk:workflow", operation: "select",
  select: { node: {expr: "@internalName"} } 
}
})
```

XML和JXON语法之间的等效示例：

> **E4X：**
>
> ```xml
>                             <queryDef schema="nms:delivery" operation="get">
>     <select>
>         <node expr="@created"/>
>         <node expr="@lastModified"/>
>     </select>
>     <where>
>         <condition expr="@id=123456"/>
>     </where>
> </queryDef>
> ```
>
> **JXON：**
>
> ```javascript
>                             {queryDef: {schema: "nms:delivery", operation: "get", 
>     select: {
>         node: [
>             {expr: "@created"}, 
>             {expr: "@lastModified"}]
>         }, 
>     where: {
>         condition: {expr: "@id=123456"}
>     }
> }}
> ```

有关JXON语法的详细信息，请参阅使用XML页面。

## SOAP调用

这些SOAP方法必须运行NLWS对象属性。 架构的JavaScript ID是从命名空间和以大写开头的名称创建的。 例如， nms:delivery架构将使用nmsDelivery作为其JS ID。

> **旧：**
>
> ```javascript
> nms.delivery.Play(deliveryId);
> ```
>
> **新：**
>
> ```javascript
> NLWS.nmsDelivery.Play(deliveryId);
> ```

## SOAP JavaScript方法

要接收其参数采用DOM格式而不是E4X格式的XML文档，必须将dom=&quot;true&quot;属性添加到架构中。

## 多行字符串

使用XML构建多行字符串必须替换为字符串的串联，因为忘记添加\\n行的结尾。

> **旧：**
>
> ```xml
> <str>line 1
> line 2
> line 3
> </str>.toString()
> ```
>
> **新：**
>
> ```javascript
> "line 1\n" +
> "line 2\n" +
> "line 3\n"
> ```

## 内容管理

在预览期间，需要在发布模板上或JavaScript模板中激活DOM选项。 对于具有JavaScript预处理功能的XSL转换，您还必须激活DOM选项（聚合器窗口）。
