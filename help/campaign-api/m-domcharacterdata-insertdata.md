# 插入数据

在文本的特定位置插入字符串。

```text
insertData (offset, arg)
```

## 参数

**offset**&#x200B;插入位置（第一个字符为0）。

要插入的&#x200B;**arg**&#x200B;字符串。

## 返回值

无。

## 功能

**类的方法：** [DOMCharacterData](c-domcharacterdata.md)

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
