# DOMDocument（类）

XML文档。

## 方法

| 方法 | 描述 |
| --- | --- |
| [DOMDocument](m-domdocument-domdocument.md) | 创建新文档。 |
| [fromXMLString](m-domdocument-fromxmlstring.md) | 从XML字符字符串创建新文档。 |
| [fromJXON](m-domdocument-fromjxon.md) | 从JXON对象创建新文档。 |
| [加载](m-domdocument-load.md) | 从XML文件创建新文档。 |
| [toXMLString](m-domdocument-toxmlstring.md) | 将XML文档转换为字符串。 |
| [createElement](m-domdocument-createelement.md) | 创建新元素。 |
| [createElementNS](m-domdocument-createelementns.md) | 使用指定的名称和命名空间创建新元素。 |
| [createTextNode](m-domdocument-createtextnode.md) | 创建新的文本类型节点。 |
| [createComment](m-domdocument-createcomment.md) | 创建新的注释类型节点。 |
| [createCDATASection](m-domdocument-createcdatasection.md) | 创建新的CDATA类型节点。 |
| [createProcessingInstruction](m-domdocument-createprocessinginstruction.md) | 创建新的处理指令。 |
| [createEntityReference](m-domdocument-createentityreference.md) | 创建新实体引用。 |
| [getElementsByTagName](m-domdocument-getelementsbytagname.md) | 返回具有指定名称的所有元素的列表。 |
| [getElementsByTagNameNS](m-domdocument-getelementsbytagnamens.md) | 返回具有指定名称和命名空间的所有文档元素的列表。 |
| [getElementById](m-domdocument-getelementbyid.md) | 返回具有指定ID的元素。 |
| [importNode](m-domdocument-importnode.md) | 从另一文档创建节点副本。 |
| [normalizeDocument](m-domdocument-normalizedocument.md) | 规范化文档：替换图元参照并融合相邻文本节点。 |
| [renameNode](m-domdocument-renamenode.md) | 更改元素或属性的名称。 |
