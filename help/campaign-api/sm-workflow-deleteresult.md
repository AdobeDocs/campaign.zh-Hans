# DeleteResult

擦除一个或多个活动的结果。

```text
DeleteResult ( String workflowId, String activityName )
```

## 参数

**workflowId**&#x200B;工作流的标识符或内部名称。

**activityName**&#x200B;要擦除其结果的活动的名称

## 返回值

无。
