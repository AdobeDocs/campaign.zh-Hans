# 处置

释放对象使用的资源。

```text
dispose ()
```

## 参数

无。

## 返回值

无。

## 备注

此方法可用于释放对象使用的资源，而无需等待垃圾回收器或脚本结尾完成对象。

## 功能

**类的方法：** [FTP](c-ftp.md)

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
