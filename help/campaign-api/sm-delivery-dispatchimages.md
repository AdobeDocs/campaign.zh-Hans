# 分派图像

告诉应用程序服务器将图像发送到中间源服务器。

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## 参数

**图像**&#x200B;要上载到中间源服务器的图像列表。

投放路由器的&#x200B;**providerId**&#x200B;标识符。

投放路由器的&#x200B;**providerName**&#x200B;名称。

## 返回值

无。

## 功能

**架构：** [nms:delivery](s-nms-delivery.md)

**静态：**

是
