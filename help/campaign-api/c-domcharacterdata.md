# DOMCharacterData（类）

仅包含文本的节点。 它可以是文本类型节点或注释。

## 方法

| 方法 | 描述 |
| --- | --- |
| [substringData](m-domcharacterdata-substringdata.md) | 提取部分文本。 |
| [appendData](m-domcharacterdata-appenddata.md) | 向文本添加字符串。 |
| [insertData](m-domcharacterdata-insertdata.md) | 在文本的特定位置插入字符串。 |
| [deleteData](m-domcharacterdata-deletedata.md) | 删除部分文本。 |
| [replaceData](m-domcharacterdata-replacedata.md) | 替换部分文本。 |

## 属性

| 属性 | 描述 |
| --- | --- |
| [数据](p-domcharacterdata-data.md) | 节点的文本值。 |
| [长度](p-domcharacterdata-length.md) | 节点中的字符数。 |
