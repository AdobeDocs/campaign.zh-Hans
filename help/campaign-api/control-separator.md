# 分隔符

显示带有文本和图像的分隔符。

![分隔符控件](assets/separator.70317a27.png)

## 属性

**方向 — 默认情况下为string** Horizontal。

**img — 字符串**&#x200B;关联的图像。

**标签 — 要显示的字符串**&#x200B;文本。

## 备注

示例：

```xml
      <static type="separator" label="Please enter your name here."/>

<static type="separator">Please enter your name here.</static>
```
