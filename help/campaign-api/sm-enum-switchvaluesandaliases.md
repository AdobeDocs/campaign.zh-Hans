# SwitchValues和Aliases

将值转换为别名，然后反向转换。

```text
SwitchValuesAndAliases ( XML enums, String mode )
```

## 参数

要转换的枚举的&#x200B;**枚举**&#x200B;集合。

**mode**&#x200B;转换模式：必须为“ValuesToAliases”或“AliasesToValues”。

## 返回值

无。

**架构：** [xtk:enum](s-xtk-enum.md)

**静态：**

是
