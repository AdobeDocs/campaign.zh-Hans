# createElementNs

使用指定的名称和命名空间创建新元素。

```text
createElementNS (namespaceURI, qualifiedName)
```

## 参数

**命名空间URI**&#x200B;命名空间URI。

**qualifiedName**&#x200B;要创建的元素的限定名称。

## 返回值

已创建[元素](c-domelement.md)。
