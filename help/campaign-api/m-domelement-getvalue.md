# getValue

返回给定XPath引用的节点值。

```text
getValue (xpath)
```

## 参数

**xpath**&#x200B;路径。

## 返回值

引用的节点的文本值。

## 备注

XPath的语法只接受XPath语言子集。 如果路径格式不正确，则会引发异常。
