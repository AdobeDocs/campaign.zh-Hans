# reverseLink

如果元素是链接，则返回表示反向链接的[SchemaNode](c-schemanode.md)对象（通过目标架构）。 如果未定义，则属性不会定义。

```text
reverseLink
```

## 功能

**类的属性：** [SchemaNode](c-schemanode.md)

**只读：**

是

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
