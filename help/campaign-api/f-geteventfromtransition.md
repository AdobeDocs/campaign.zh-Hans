# getEventFromTransition

返回进行给定过渡的最后一个事件。

```text
getEventFromTransition (transitionName)
```

## 参数

**transitionName**&#x200B;过渡的内部名称。

## 返回值

已进行给定过渡或空值的最后一个事件。 对象对应于“xtk:workflowEvent”架构中的实体。
