# Cookie（类）

表示由servlet和Web浏览器交换的Cookie。

## 属性

| 属性 | 描述 |
| --- | --- |
| [名称](p-cookie-name.md) | Cookie名称。 |
| [评论](p-cookie-comment.md) | 描述Cookie函数的注释，如果未定义，则为null。 |
| [域](p-cookie-domain.md) | Cookie的域名。 |
| [maxAge](p-cookie-maxage.md) | Cookie的有效期（秒）。 |
| [路径](p-cookie-path.md) | Web浏览器转发Cookie时所依据的路径。 |
| [安全](p-cookie-secure.md) | 如果Cookie只能通过安全协议转发，则为true。 |
| [值](p-cookie-value.md) | Cookie值。 |
| [版本](p-cookie-version.md) | 与Cookie兼容的协议版本。 |

## 功能

**可用位置：**

* JSSP
* WebApp
