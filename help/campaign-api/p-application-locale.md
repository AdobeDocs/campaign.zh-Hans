# 区域设置

返回与实例Local匹配的字符字符串。

```text
locale
```

## 备注

“本地”是定义区域设置的代码。 它由语言代码和国家/地区代码组成，以“ — ”分隔。 值示例：

* en-US — 英语，美国
* en-GB — 英语，英国
* fr-FR — 法语，法国
* de-DE — 德语，德国
* es-ES — 西班牙语，西班牙
