# EnumerationValue（类）

表示枚举值的定义。

## 属性

| 属性 | 描述 |
| --- | --- |
| [标签](p-enumerationvalue-label.md) | 返回提供当前枚举值的简短说明的字符串。 |
| [描述](p-enumerationvalue-description.md) | 返回提供当前枚举值说明的字符串。 |
| [值](p-enumerationvalue-value.md) | 返回提供当前枚举值值的字符串。 |
| [名称](p-enumerationvalue-name.md) | 返回提供当前枚举值名称的字符串。 |
| [图像](p-enumerationvalue-image.md) | 返回一个字符串，其中提供当前枚举值的图像名称。 |
| [enabledIf](p-enumerationvalue-enabledif.md) | 返回提供当前枚举值的有效性条件的字符串。 |

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 类型规则
* JSSP
* SOAP方法
* WebApp
* 工作流
