# Executinstance

立即执行工作流并等待它完成。

```text
workflow.ExecuteInstance ( Boolean simulationMode, Boolean keepResult, Boolean logSQL )
```

## 参数

**simulationMode**&#x200B;执行模拟。

**keepResult**&#x200B;保留中期结果。

**logSQL**&#x200B;是否需要保存SQL订单的跟踪？

## 返回值

无。
