# fromString

在缓冲区中加载字符串的内容。

```text
fromString (string [, codepage ])
```

## 参数

**字符串**&#x200B;字符串。

**代码页**&#x200B;用于序列化缓冲区中的字符串的代码页。 此可选参数允许您指定字符编码。 例如：

* iso-8859-1
* utf-8
* utf-16
* us-ascii
* shift-jis
* euc-kr

## 返回值

无。
