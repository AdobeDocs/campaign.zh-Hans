# lookupNamespaceURI

搜索链接到给定前缀的命名空间的URI。

```text
lookupNamespaceURI (prefix)
```

## 参数

**前缀**&#x200B;前缀。

## 返回值

命名空间的URI，如果未找到，则为空字符串。
