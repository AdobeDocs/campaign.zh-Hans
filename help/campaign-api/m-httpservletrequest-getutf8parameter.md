# getUTF8参数

返回查询参数的值（以UTF-8编码）。

```text
getUTF8Parameter (name)
```

## 参数

**名称**&#x200B;参数名称。

## 返回值

所请求参数的值。

## 功能

**类的方法：** [HttpServletRequest](c-httpservletrequest.md)

**可用位置：**

* JSSP
* WebApp
