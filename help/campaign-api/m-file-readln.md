# readlan

读取文本文件的一行。

```text
readln ()
```

## 参数

无。

## 返回值

包含文件下一行的字符串，如果达到文件结尾，则为⌐null。

## 备注

示例：

```javascript
var f = new File("c:/dummy.xml")
f.open("r", File.CODEPAGE_UTF8)
var line
while( line = f.readln() )
  logInfo(line)
f.close()
```
