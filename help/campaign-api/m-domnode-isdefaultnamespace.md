# isDefaultNamespace

测试给定的命名空间是否为默认值。

```text
isDefaultNamespace (namespaceURI)
```

## 参数

**命名空间URI**&#x200B;命名空间URI。

## 返回值

如果namespaceURI是默认命名空间，则为true ；否则为false。
