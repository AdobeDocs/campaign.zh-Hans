# GetNewIdsEx

给定序列名称的情况下从数据库中获取唯一标识符列表。

```text
String idList = GetNewIdsEx ( Number count, String sequence )
```

## 参数

**count**&#x200B;此方法应返回的标识符数

**序列**&#x200B;要递增的序列的名称

## 返回值

**idList**&#x200B;逗号分隔的标识符列表

**架构：** [xtk:session](s-xtk-session.md)

**静态：**
