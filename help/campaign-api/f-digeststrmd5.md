# digestStrMd5

> 警告：
>
> 不得使用此函数根据个人信息创建哈希。

计算字符串的MD5哈希函数。 该字符串在计算之前自动使用UTF-8进行编码。

```text
digestStrMd5 (string)
```

## 参数

**字符串**&#x200B;要为其计算哈希函数的字符串。

## 返回值

作为参数传递的字符串的MD5哈希值。

## 功能

**可用位置：**

* 内容管理
* 投放属性
* 投放消息
* 类型规则
* 导入
* JSSP
* SOAP方法
* WebApp
* 工作流
