# appendBase64

将数据从以base 64编码的字符串附加到缓冲区的末尾。

```text
appendBase64 (string)
```

## 参数

**字符串**&#x200B;一个字符串，表示要添加到缓冲区的二进制数据（以base 64编码）。

## 返回值

无。
